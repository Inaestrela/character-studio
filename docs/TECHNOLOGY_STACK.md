# 1. Technology Stack

| Layer | Technology | Purpose |
|--------|------------|---------|
| Language | TypeScript | Type safety and editor support |
| Build Tool | Vite | Fast React development |
| UI | React | Application framework |
| 3D Engine | React Three Fiber + Three.js | Browser rendering |
| Helpers | Drei | Camera, lighting and loaders |
| State | Zustand | Character state management |
| Styling | Tailwind CSS | UI styling |
| Asset Format | glTF / GLB | Modular assets |
| Modeling | Blender | Asset creation |
| Print Storage | Serverless + S3 | Future print workflow |
| Hosting | Vercel / Netlify | Web deployment |
